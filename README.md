# Minecraft

Atividade Aula-05 Desenvolvimento Front-End para Web.

# Projeto Minecraft - HTML Puro

Projeto acadêmico desenvolvido somente com HTML, sem CSS e sem JavaScript.

# Estrutura

html/: 12 páginas HTML interligadas por um menu presente em todas.

img/: imagens usadas com img, figure e figcaption.

audio/: áudio local usado com audio controls.

video/: vídeo local usado com video controls.

# Páginas

1. index.html
2. historia.html
3. modos-de-jogo.html
4. sobrevivencia.html
5. criativo.html
6. mobs.html
7. blocos.html
8. biomas.html
9. dimensoes.html
10. ferramentas.html
11. curiosidades.html
12. cadastro.html

# Conteúdos HTML utilizados

Tags semânticas: header, nav, main, section, article, aside e footer.

Listas, links, tabelas e formulários.

fieldset, legend e label.

Áudio e vídeo.

figure e figcaption.

Inputs date, file, color e range.

required e placeholder.

datalist.

details e summary.

mark, del, ins, abbr, blockquote, progress e meter.
